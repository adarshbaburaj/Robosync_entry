Compatible return contract
--------------------------
policy.smolvla.eval(env, model, obs) now returns exactly:
    (final_obs, info, truncated, inference_times_s)
info and truncated are the original values returned by the environment.
The adapter stops its action loop at success, truncation or termination so
it does not continue executing queued actions beyond an episode boundary.
This matches the success/timeout handling expected by scripts/eval_policy.py.

Genuine timing and cache handling
--------------------------------
The shared official policy/inference_timing.py is used without modification.
Its start_inference/finish_inference functions synchronize a supplied CUDA
device and use time.perf_counter(). No fixed, zero, estimated or synthesized
latency is submitted to the evaluator.

The worker uses these functions on its own requested device. It inspects
the pinned LeRobot policy's real _check_get_actions_condition() before each
select_action to detect action-queue refills. Cached-only requests return an
empty inference_times_s list. Requests performing real model inference return
one measured worker timing sample. n_action_steps is validated in [1, the
checkpoint's n_action_steps], so there can be at most one refill per request.
All five selected checkpoints have n_action_steps=50; smolvla_steps stays 10.

The parent uses the same official functions to measure the evaluator's full
scope: raw observation encoding, NPZ serialization/transport, worker processing,
model inference, saved postprocessor, returned actions and executable action
tensor conversion. It synchronizes the simulator device; the blocking worker
reply follows worker-device synchronization and CPU action materialization.
The parent finishes timing BEFORE env.step or diagnostic printing. This avoids
confusing the worker's masked GPU ordinal with the parent's physical GPU.

Exactly one original parent wall-clock sample is returned for a request with
a real refill, and [] for a cached-only request. Parent and worker durations
are independently measured and are never added, divided, or substituted with
constants. Worker timings remain available as last_inference_times_s for audit;
the fourth evaluator return contains the full parent scope. As before, each
request returns up to ten actions; model/action chunking itself is unchanged.
Action dimension/finiteness and timing protocol are validated before env.step.
Episode reset clears both the model queue and client timing metadata.
